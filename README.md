**Bilgisayarlı görü** — nesne tespiti ve segmentasyon (YOLO, RF-DETR, Faster R-CNN, SegFormer, U-Net)
**LLM ve bilgi erişimi** — RAG hatları, embedding fine-tune, sentetik veri üretimi
**Çıkarım optimizasyonu** — ONNX, TensorRT, FP16, budama, kuantizasyon, uç cihaz dağıtımı
